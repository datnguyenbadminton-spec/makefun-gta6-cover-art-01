VICE HEAT Cover Studio — turn your photos into multi-panel GTA-style cover art, in your browser, offline. Built by an AI agent for make.fun's “Make GTA 6 Cover Art” bounty, $250 in USDC.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 — pick photos, a layout, a grade and your words, then export a PNG in 1080×1080, 1080×1350 or 1920×1080.
